# n8n CLI Management Tool 🚀

一个专为 **Debian 12+** / **Ubuntu 22.04+** 环境打造的 n8n 一键部署与命令行管理工具。支持自动化安装、Nginx 反代配置、Let's Encrypt SSL 证书申请、容器健康检查、资源监控、数据备份恢复，并深度集成了与官方引擎解耦的中文汉化支持。


## ✨ 核心特性

* 📦 **一键自动化部署**：自动检测并安装 Docker 与 Compose 环境，配置虚拟内存 (Swap) 防 OOM，自动生成高强度加密密钥与初始账号。
* 🌐 **自建流水线与中文解耦**：从专属自建流水线 (`zdaben/n8n-chinese`) 动态匹配汉化补丁。**官方引擎版本与汉化包彻底解耦**，汉化包未出时自动安全降级使用官方原生 UI，彻底杜绝跨版本白屏。
* 🔐 **自动反代与 SSL**：集成了 Nginx 自动化反向代理与 Certbot 证书申请，开箱即用支持 HTTPS。
* 🛡️ **完善的数据灾备**：自动配置每日凌晨 3 点定时全量备份（保留 7 天），支持命令行一键打包与按编号快速回滚恢复。
* 🩺 **服务健康熔断探针**：部署与升级后内置 `/healthz` 健康检查轮询机制，避免容器启动失败或静默崩溃。
* 📊 **直观的运维监控**：提供容器状态查看（静态快照）与实时资源监控（Top 模式）。
* 🧹 **绿色纯净卸载**：支持一键清理所有相关容器、本地数据、Nginx 配置和定时备份任务。


## 🛠️ 系统要求

* **操作系统**：Debian 12 及以上版本 (推荐) / Ubuntu 22.04+
* **权限要求**：必须使用 `root` 用户执行。
* **网络要求**：如果使用域名，请确保域名已正确解析至本机 IP（CDN 代理用户可忽略 IP 一致性校验）。


## 🚀 快速开始

### 1. 下载并赋予执行权限
您可以将此脚本直接下载到系统的环境变量路径中，方便全局调用：

```bash
apt update -y && apt install curl wget sudo jq -y && curl -sSLo /usr/local/bin/n8n https://raw.githubusercontent.com/zdaben/n8n_install/main/n8n.sh && chmod +x /usr/local/bin/n8n && n8n install
```

### 2. 执行安装

```bash
n8n install
```
根据终端提示，依次输入您的**绑定域名**、**SSL 申请邮箱**以及**宿主机内部映射端口**（默认 5678）。系统将自动完成环境准备、配置生成、汉化匹配与反代证书签发。


## 🧰 命令列表
在终端中直接输入 `n8n` 即可调出管理面板并查看运行信息（访问地址、管理账号、密码、密钥等）。其他快捷指令如下：

| 命令 | 功能描述 |
| --- | --- |
| `n8n` | 显示管理面板、访问信息及当前运行状态 |
| `n8n install` | 首次全新安装或修改当前配置（覆盖重装） |
| `n8n update` | 检查并更新官方最新 Stable 引擎及匹配的汉化补丁 |
| `n8n status` | 查看当前运行版本及 Docker 容器资源静态快照 |
| `n8n top` | 进入实时动态监控模式，查看 CPU / 内存占用情况 |
| `n8n restart` | 重启 n8n 容器服务 |
| `n8n backup` | 立即执行数据目录与配置文件的打包备份 |
| `n8n recover` | 呼出恢复面板，从历史归档中选择指定编号恢复数据 |
| `n8n uninstall` | 【危险】卸载服务并彻底清理所有数据、配置及定时任务 |


## 📂 目录结构与数据挂载
所有核心数据均默认持久化存储在宿主机 `/root/n8n` 目录下，方便随时备份或迁移：

```plaintext
/root/n8n/
├── n8n_data/           # n8n 核心数据库与用户配置 (.n8n 目录)
├── n8n_files/          # n8n 本地文件目录，供工作流读写本地文件
├── n8n_ui/             # 汉化补丁 UI 资源挂载目录 (仅在匹配汉化时挂载)
├── backup/             # 自动与手动备份的 .tar.gz 归档存放处
└── docker-compose.yml  # 核心容器编排配置文件
```


## 💡 常见问题与注意事项

1. **域名解析 IP 不一致警告**：
如果您使用了 Cloudflare 等 CDN 代理，脚本检测到解析 IP 与服务器物理 IP 不一致时会触发提示。这是正常现象，输入 `y` 确认继续即可。
2. **忘记管理员密码或加密密钥**：
直接在终端执行 `n8n`，面板将直接打印出 `docker-compose.yml` 中记录的访问地址、账号、密码及加密密钥。
3. **汉化补丁更新与防白屏机制（V2 特性）**：
官方发布新版本后，脚本会优先从 [`zdaben/n8n-chinese`](https://github.com/zdaben/n8n-chinese) 匹配汉化包。若当前最新版本尚未生成汉化补丁，**脚本会自动移除 UI 挂载并使用官方原生界面**，确保系统始终能安全升级，绝不会因版本错配而导致前端白屏。
4. **SSL 证书续签**：
安装时已通过 Certbot 自动配置证书。证书到期前系统通常会自动续签，若遇到问题，可手动执行 `certbot renew`。
